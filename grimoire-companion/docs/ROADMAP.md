# Roadmap

Grimoire currently provides a native companion, a CAVA spectrum, bounded task readers, explicit generic events, result and handoff opening, two palettes, a data-only skin format, tray recovery, and local logs.

Potential future work:

- Add adapters for well-defined local job status APIs while keeping reads bounded and explicit.
- Add optional frame sequences to the existing skin format.
- Explore MPRIS media controls with clear behavior when the player exits.
- Improve Wayland and multi-monitor placement after testing on those compositors.
- Stabilize schemas before adding a public theme gallery or external adapters.

These are candidates, not promised releases. Status remains tied to recorded evidence.
